  pwd - print the working directory
  Prints the full path of the working directory: the one the prompt shows, with ~ written out.
[Usage:]
  pwd [-L|-P]

  Options:
    -L  print the path with its symbolic links (the default)
    -P  print the physical path, with links resolved
[Examples:]
    pwd
    pwd -P
See also: cd, ls
  cd - change the working directory
  Changes the shell's working directory to DIR, or to $HOME when there is none. 'cd -' returns to the previous directory ($OLDPWD) and prints it. The prompt shows where you are.
[Usage:]
  cd [-L|-P] [DIR]
  cd -

  Options:
    -L  keep symbolic links in the path (the default)
    -P  use the physical directory, with links resolved
[Examples:]
    cd documents  go into a folder
    cd ..  up one level
    cd ~  home
    cd /tmp; cd -  there, and back to the previous folder
See also: pwd, ls

keys - show or hide the key bar on touch screens
On a touch screen, a bar of keys rides above the keyboard: tab, ↑ and ↓ for history (hold ↑ for the list), ^C, clear, ••• for symbols, and ⌄ to put the keyboard away. With 'auto', the default, it goes once a hardware keyboard is used, and the suggestion chips stay; 'on' always shows it and 'off' never does. The setting is remembered. With no argument, says which is in force.
Usage:
keys
keys auto|on|off

Options:
      --help  display the keys and this help, and exit
Examples:
  keys  which is in force
  keys on  always show the key bar
  keys auto  the default
See also: help
