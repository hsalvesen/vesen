$ help pwd cd
[terminal]
  pwd - print the working directory
  Prints the full path of the working directory: the one the prompt shows, with ~ written out.
[Usage:]
  pwd [-L|-P]

  Options:
    -L  print the path with its symbolic links (the default)
    -P  print the physical path, with links resolved
[Examples:]
    pwd
    pwd -P
See also: cd, ls
  cd - change the working directory
  Changes the shell's working directory to DIR, or to $HOME when there is none. 'cd -' returns to the previous directory ($OLDPWD) and prints it. The prompt shows where you are.
[Usage:]
  cd [-L|-P] [DIR]
  cd -

  Options:
    -L  keep symbolic links in the path (the default)
    -P  use the physical directory, with links resolved
[Examples:]
    cd documents  go into a folder
    cd ..  up one level
    cd ~  home
    cd -  back to the previous folder
See also: pwd, ls
