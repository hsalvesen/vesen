PWD(1)       User Commands        PWD(1)

NAME
   pwd - print the working directory

SYNOPSIS
   pwd [-L|-P]

DESCRIPTION
   Prints the full path of the working
   directory: the one the prompt shows,
   with ~ written out.

OPTIONS
   -L
      Print the path with its symbolic
      links (the default).
   -P
      Print the physical path, with
      links resolved.
   --help
      Display this help and exit.

EXAMPLES
   pwd
   pwd -P
