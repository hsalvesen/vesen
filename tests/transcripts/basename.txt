# basename: one session, with stdout on the terminal and into a pipe, at 40, 80 and 120 columns.
# Rows starting with "! " went to stderr, and "? N" is the exit status. Where the variants
# differ, each output is under the variants it belongs to. See README.md.

$ basename /usr/bin/ls
ls
? 0
$ basename documents/linux.txt .txt
linux
? 0
$ basename -s .sh scripts/backup.sh bin/deploy
backup
deploy
? 0
$ basename a b c
! basename: extra operand 'c'
! Try 'basename --help' for more information.
? 1
